## ✨ 프로젝트 개요 (Project Overview)
- 제목 : 캐치테이블 클론 코딩
- 핵심 목표 : 캐치테이블 예약금 결제
- 데모 링크 : [캐치테이블](https://app.catchtable.co.kr/)
</br>

##  🛠️ 주요 기능 (Key Features)
- 사용자/고객 측 기능 :
  
  - 레스토랑 검색 및 필터링 : 지역, 날짜, 인원, 카테고리별 검색
  - 실시간 예약 : 잔여 좌석 확인 및 예약금 결제
  - 웨이팅 등록 및 현황 확인
  - 리뷰 및 평점 확인/작성
  - 마이페이지 : 예약 내역 확인 및 수정/취소
</br>

## 🏗️ 기술 스택 (Tech Stack)
| 구분 | 기술 스택 (Stack) | 설명 및 사용 목적 |
| :-: | :-: | :-: |
| Frontend | React / TypeScript, Tailwind CSS | 사용자 인터페이스 구현, 복잡한 상태 관리 |
| Backend | Spring Boot, Java, RESTful API | 예약금 로직, 데이터베이스 연동 |
| Database | PostgreSQL | 예약 정보, 사용자 정보 등 데이터 저장 |
| Etc. | Git, GitHub | 버전 관리 및 협업 |

## 📜 커밋 메시지 규칙: Conventional Commits
| Type |	설명 |	예시 |
| --- | :-: | :-: |
| feat |	새로운 기능 추가 | `feat: 레스토랑 실시간 예약 기능 추가` |
| fix |	버그 수정 |	`fix: 마이페이지 예약 취소 시 오류 수정` |
| docs |	문서 변경 (README) | `docs: README.md에 기술 스택 업데이트` |
| style |	코드 포맷팅, 세미콜론, 공백 등 (코드 로직 변경 없음) |	`style: 함수 선언부 공백 제거 및 포맷팅` |
| refactor |	코드 리팩토링 (기능 변경 없이 코드를 개선) |	`refactor: 예약 확인 로직을 서비스 레이어로 분리` |
| test | 테스트 코드 추가 또는 수정 |	`test: 예약 확인 API 유닛 테스트 추가`|
| chore |	빌드 시스템, 라이브러리 설치 등 기타 변경 사항 (주로 package.json 수정 등) |	`chore: react 버전 13.5로 업데이트`|
